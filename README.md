# ETS2 Achievement Assistant

### Планируйте достижения. Находите нужные заказы. Видите цели на карте.

Помощник достижений прямо в Euro Truck Simulator 2.

**[Скачать установщик](https://github.com/Rammstik/truck-achievement-assistant/releases/download/ets2-v0.6.17/ETS2-Achievement-Assistant-Setup-0.6.17.exe)** · **[Все загрузки](https://github.com/Rammstik/truck-achievement-assistant/releases)** · **[Сообщить о проблеме](https://github.com/Rammstik/truck-achievement-assistant/issues)**

**0.6.17** · ETS2 **1.62.2.1** · Windows x64 · DirectX 11

</div>

Добавьте достижение в план — помощник покажет доступные подробности прогресса, подсветит поддерживаемые цели на карте и отберёт подходящие предложения в списках заказов. Панель открывается сочетанием **Ctrl+F8**.

> Текущая версия предназначена для ETS2 **1.62.2.1**. Установщик проверяет совместимость перед копированием файлов. После обновления игры может потребоваться новая версия помощника.

## Возможности

| Возможность | Что делает помощник |
| --- | --- |
| **План достижений** | Собирает выбранные цели в одном месте и сохраняет план между запусками. |
| **Подробный прогресс** | Показывает условия, города, предприятия и грузы по данным Steam, сохранений и журнала доставок. |
| **Подсветка карты** | Выделяет красным поддерживаемые города, предприятия, обзорные и дорожные точки, некоторые сервисы. |
| **Фильтр заказов** | Оставляет предложения для достижений из плана. Несколько достижений объединяют подходящие заказы. |
| **Исключение выполненного** | Убирает подтверждённые пункты из кандидатов; неизвестный прогресс не считается выполнением. |
| **Выбор маршрута** | Позволяет отдельно включить фильтр доставок в непосещённые города. По умолчанию он выключен. |
| **Русский и английский** | При первом запуске используется язык игры: русский для русского, английский для остальных. Язык можно изменить в настройках. |

### Как работает план

1. Добавили достижение с поддерживаемыми условиями доставки — появились подходящие предложения.
2. Добавили ещё одно — список объединил кандидатов для обеих целей.
3. Убрали достижение — заказы, подходившие только для него, исчезли из отбора.
4. Подходящих предложений нет — список пуст; причина отображается в помощнике.
5. Убрали все достижения с доставками — вернулся обычный список заказов.

Подсветка целей на карте работает независимо от переключателя фильтра доставок в непосещённые города: можно взять дальний заказ и проехать через нужный город по пути.

## Установка

1. **Закройте ETS2.**
2. **[Скачайте и запустите установщик](https://github.com/Rammstik/truck-achievement-assistant/releases/download/ets2-v0.6.17/ETS2-Achievement-Assistant-Setup-0.6.17.exe).** Он ищет игру в библиотеках Steam. При необходимости укажите папку `Euro Truck Simulator 2` вручную.
3. **Запустите игру и нажмите Ctrl+F8.** Выберите профиль и добавьте достижения в план.

Python и инструменты разработки для обычной установки не нужны. Установщик обновляет файлы помощника, игровые сохранения не изменяются. Если Windows запрещает запись в папку игры, запустите установщик от имени администратора.

Пока панель открыта, мышь и клавиатура управляют помощником. Повторное **Ctrl+F8** закрывает панель.

### Язык помощника

Откройте **Настройки → Язык** и выберите **Язык игры (автоматически)**, **Русский** или **English**. По умолчанию помощник следует языку игры: русский включается для русского языка, английский — для любого другого. Ручной выбор сохраняется между запусками и меняет язык панели сразу, без перезапуска игры.

<details>
<summary><strong>Ручная установка из Portable</strong></summary>

Скачайте [Portable 0.6.17](https://github.com/Rammstik/truck-achievement-assistant/releases/download/ets2-v0.6.17/ETS2-Achievement-Assistant-Portable-0.6.17.zip), закройте игру и скопируйте содержимое папки `bin` из архива в каталог ETS2 с объединением папок.

В `bin/win_x64/plugins` должны находиться:

```text
AchievementAssistant.dll
AchievementAssistant/
  AADataWorker.exe
  _internal/
map-probe.json
```

Сохраните уже существующий `map-probe.json`, если меняли его настройки. Лицензии компонентов находятся в папке `licenses` архива.

Для удаления Portable закройте игру и удалите только `AchievementAssistant.dll` и папку `AchievementAssistant`.

</details>

## Совместимость и ограничения

| Компонент | Состояние |
| --- | --- |
| ETS2 | **1.62.2.1**, Windows x64, DirectX 11 |
| Другие версии ETS2 | Нужна совместимая сборка помощника; привязки проверяются по точному файлу игры. |
| ATS | Исходники включены в общий проект. Текущий установщик предназначен только для ETS2. Сборка ATS 0.1.0 рассчитана на 1.61.3.18. |
| Подробные правила | **110 из 114** достижений Steam, включая все четыре достижения Исландии. |

Наличие подробного правила не означает поддержку каждого условия фильтром или картой. Часть прогресса обновляется после сохранения игры. Отсутствие записи в журнале не доказывает невыполнение; неизвестные пункты остаются кандидатами. Некоторые условия предложения, включая точный маршрут Special Transport, недоступны для полной автоматической проверки.


## Обновление и удаление

**Обновление:** закройте игру и запустите новый установщик, выбрав ту же папку ETS2.

**Удаление:** откройте список установленных приложений Windows и выберите **ETS2 Achievement Assistant**. План и настройки сохраняются в `%LOCALAPPDATA%\ETS2AchievementAssistant`. Другие плагины, сохранения игры и общий `map-probe.json` сохраняются.

## Исходники и сборка

Исходный код ETS2 и ATS доступен в этом репозитории. Движок общий, DLL собирается отдельно для каждой игры.

**[Скачать исходники текущей версии проекта (ZIP)](https://github.com/Rammstik/truck-achievement-assistant/archive/refs/heads/main.zip)**

| Каталог | Содержимое |
| --- | --- |
| [work/native-assistant](work/native-assistant) | DLL, интерфейс, игровые привязки и нативные тесты. |
| [work/achievement-core](work/achievement-core) | Чтение сохранений, данные Steam и правила достижений. |
| [work/achievement-lab](work/achievement-lab) | Проверки правил и фильтров. |
| [installer](installer) | Установщик ETS2 и проверка установки/удаления. |
| [publication](publication) | Документация и публикация выпусков. |

Для сборки нужны **Windows x64**, **PowerShell 7**, **Visual Studio Build Tools** с C++ x64 и Windows SDK, **Python 3.11**, а для установщика — **Inno Setup 7**.

```powershell
python -m pip install -r requirements-build.txt

# DLL и общий обработчик данных
./work/native-assistant/build.ps1 -Game ets2
./work/native-assistant/build_worker.ps1

# Пакет и установщик
python ./installer/prepare_payload.py
./installer/build.ps1 -Compiler 'C:/Program Files/Inno Setup 7/ISCC.exe'
```

Файлы для распространения появятся в `outputs/public`. Если изменился хеш DLL, сначала проверьте новую сборку и обновите `installer/release.json`: упаковка намеренно отклоняет непроверенный файл.

Для сборки DLL ATS используйте `build.ps1 -Game ats`. Сохранения, настройки пользователей, исследовательские дампы и готовые сборки в Git не включены. Лицензии сторонних компонентов находятся рядом с их исходниками и включены в дистрибутив. Отдельная открытая лицензия для собственного кода проекта пока не назначена.
