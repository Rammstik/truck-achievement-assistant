ETS2 Achievement Assistant 0.6.15 для ETS2 1.62.1.0.

- Обновлены привязки карты и списков заказов к ETS2 1.62.1.0; проверка точного исполняемого файла сохранена.
- Обновлены координаты предприятий, сервисов и городские зоны.
- Сохранены красная подсветка целей, объединение фильтров плана и исключение подтверждённых пунктов.
- Добавлен установщик с поиском библиотек Steam, проверкой совместимости и удалением через Windows.

Закройте игру перед установкой. Скачайте `ETS2-Achievement-Assistant-Setup-0.6.15.exe` и выберите папку игры. Для ручной установки есть архив `Portable`.

Игровая проверка сборки подтверждена пользователем. В установщике оставлены выбор папки, установка и завершение; страница с техническими примечаниями удалена. DLL не изменена.

Подробности поддержки достижений и совместимости приведены в README проекта. Установщик предназначен для ETS2.

Контрольные суммы файлов приведены в `SHA256SUMS.txt`.
