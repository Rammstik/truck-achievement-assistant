# Подсветка целей плана на штатной карте ETS2

Требование пользователя: добавление достижения в план подсвечивает оставшиеся города, обзорные точки и другие пространственные цели прямо на игровой карте. Снятие из плана убирает подсветку; выполненные пункты исключаются. Требуются корректная работа при масштабировании, перемещении карты, разных разрешениях и DLC.

Состояние: НЕ реализовано. SDK 1.16 в поставляемых заголовках не предоставляет API для маркеров или текущей проекции интерфейса карты. Для обзорных точек есть мировые x/z. Для городов нужно извлечь координаты из фактических игровых данных. stored_world_map_zoom в сохранении не является актуальным состоянием открытой карты.

Нужен подтверждённый источник состояния карты/проекции или поддерживаемая игровыми данными динамическая подсветка. Отдельная схема, статические экранные маркеры и посещение по близости к координатам не выполняют требование. Пока способ не доказан, не заявлять готовность.
