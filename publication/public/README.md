# Помощник достижений ETS2

План достижений, красная подсветка целей на игровой карте и фильтрация подходящих заказов прямо в Euro Truck Simulator 2.

**[Скачать установщик для Windows](https://github.com/Rammstik/truck-achievement-assistant/releases/tag/ets2-v0.6.16)**

В разделе Assets выберите `ETS2-Achievement-Assistant-Setup-0.6.16.exe`. ZIP с пометкой `Portable` предназначен для ручной установки. Автоматические архивы GitHub `Source code` относятся к исходникам выбранного тега; для установки выбирайте готовый установщик или Portable.

## Совместимость

Версия помощника **0.6.16** предназначена для **ETS2 1.62.1.0, Windows x64, DirectX 11**. Установщик проверяет файл игры и не устанавливает эту сборку в несовместимую версию. После обновления ETS2 может понадобиться новая версия помощника.

ATS будет распространяться отдельно: текущий установщик предназначен только для ETS2.

## Установка

1. Закройте ETS2.
2. Запустите установщик. Он ищет игру в библиотеках Steam; при необходимости укажите папку `Euro Truck Simulator 2` вручную.
3. Запустите игру и откройте помощник сочетанием **Ctrl+F8**.
4. Выберите свой профиль и добавьте нужные достижения в план.

Python и инструменты разработки устанавливать не нужно. При установке обновляются файлы помощника; сохранения игры не изменяются.

Если Windows запрещает запись в папку игры, запустите установщик от имени администратора.

## Что умеет

- Показывает состояние достижений Steam и подробности прогресса по сохранениям и журналу.
- Подсвечивает красным доступные цели из плана: города, предприятия, обзорные и дорожные точки, некоторые сервисы.
- Отбирает предложения для достижений с доставками. Несколько достижений объединяют подходящие заказы; подтверждённые пункты исключаются, неизвестные остаются кандидатами.
- Позволяет отдельно включить отбор доставок в непосещённые города. По умолчанию он выключен, подсветка городов работает независимо.
- Сохраняет план и настройки между запусками.

Пока панель открыта, мышь и клавиатура управляют помощником. Повторное Ctrl+F8 закрывает панель.

## Язык

В настройках выберите язык игры (автоматически), Русский или English. Автоматический режим использует русский для русского языка игры и английский для любого другого. Ручной выбор сохраняется между запусками.

## Ограничения

Из 114 достижений Steam подробные правила есть для 106; восемь дополнительных целей автобусов и Исландии ещё не реализованы. Наличие подробного правила не означает поддержку каждого условия фильтром или картой. Часть прогресса обновляется после сохранения игры; отсутствие записи в журнале не доказывает невыполнение. Не все условия предложения (например, точный маршрут Special Transport) доступны для автоматической проверки.



## Обновление и удаление

Для обновления закройте игру и запустите новый установщик с той же папкой игры. Удаление доступно в списке установленных приложений Windows как **ETS2 Achievement Assistant**. План и настройки сохраняются в `%LOCALAPPDATA%\ETS2AchievementAssistant`. Другие плагины и игровые сохранения не удаляются. Общий файл настроек `map-probe.json` сохраняется.
